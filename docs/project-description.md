**Project Description:** This project is a small Python program that prints my name and today's date, and later includes a simple calculator. It is used to practice Git and GitHub.

## Goal

The goal of this project is to practice Git and GitHub. It covers creating a
repository, making commits, working with branches, merging, and pushing code
to GitHub.

## Files

- `README.md`: project title, author name, and a short description
- `.gitignore`: lists files Git should ignore, such as `__pycache__/` and `.env`
- `src/main.py`: the main program, which prints my name and today's date and
  runs the calculator functions
- `src/utils.py`: the calculator functions
- `docs/project-description.md`: this file, which describes the project

## Features

- Prints the author's name and the current date
- Calculator functions: add, subtract, multiply, and divide
- Error handling: dividing by zero raises a clear error message instead of crashing
- Developed using separate branches (`feature/calculator` and
  `feature/error-handling`) that were merged into `main
